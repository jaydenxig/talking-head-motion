# 封面

封面的作用：让人一眼知道「讲的是哪个产品、结论是什么」。

## 两个比例都要出（不要 16:9）
- 横屏 4:3，1440×1080：抖音横封面、B 站、视频号。
- 竖屏 3:4，1080×1440：抖音竖封面、小红书。

## 规则
1. **产品名必须上封面，而且是最大最醒目的字**：英文全大写、超粗斜体、蓝到青渐变。后面紧跟一句结论大字（深藏青色）。产品名 + 结论组成一行主标题，占画面宽度大半。
2. 副标题一句，关键词换色；横屏版放在蓝色毛笔刷底条上。
3. 人居中、占比大，最好有手势（伸食指指着）和看镜头的表情。
4. 横屏 4:3 信息更丰富：人两侧放从视频里提炼的界面小卡片，加一个品牌吉祥物或 3D 小机器人；底部三颗大胶囊（如「01 / 02 / 03」三个要点），每颗不同颜色并配图标。
5. 竖屏 3:4 更简洁：顶部小胶囊标签（如「真实体验 · 用了 7 天」）→ 产品名 + 结论 → 副标题 → 人像半身 → 底部三张白色小卡。
6. 整体浅蓝白底 + 细网格 + 柔光，和视频风格统一。

做完对照检查：产品名是不是全图最醒目的字？只看缩略图能不能读出结论？
