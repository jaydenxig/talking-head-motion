# 字幕

字幕就是 `template/src/sentences.js` 里的句子（`npm run timeline` 识别出来的），分镜表也按这些句子的编号写。

- 底部居中一行，白色粗字 + 深色细描边（浅色底和素材画面上都看得清），关键词用主题色。
- **只改每一行的 `text`**，不改 `id / from / to`，不增删行。句子断得不对就重跑 `npm run timeline -- --force`（会丢掉已经改的字，所以先看断句再改字）。
- 按口播稿校对错字，产品名、人名最容易识别错。
- 关键词：每句最多 1–2 个，挑核心概念、产品名、数字。写法：`'这期讲[三件事]'`。
- 英文词后面带中文意思：「take over（接管）」。
- 一句不超过一行（约 18 个字以内，识别时已经按这个长度断好）。
- **先给用户看，再烧进画面**：`npm run srt` 导出 `out/subtitles.srt`，用户确认没有错字以后再渲染。成片同时附一份 .srt，方便在剪映里改。
