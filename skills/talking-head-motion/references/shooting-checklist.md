# 拍摄清单（开拍前过一遍）

## 声音（最影响质感）
- [ ] 安静、软装多的房间（窗帘、沙发、地毯），避开空旷白墙。
- [ ] 麦克风离嘴 15–25 厘米，领夹麦最好。
- [ ] 关空调、风扇，手机开飞行模式。
- [ ] 开拍前先录 10 秒不说话的房间底噪，后期降噪用。
- [ ] 说错了停 2 秒，从这一整句重新说，后期好剪。

## 画面
- [ ] 能拍 4K 就拍 4K（要裁小圆头像、要抠像）。
- [ ] 横屏、竖屏都要发的话，横屏拍，人站在画面正中，左右多留空：竖屏版会裁出中间一条。只发竖屏就直接竖着拍。
- [ ] 腰部以上入画，头顶留一点空间，手势是表达的一部分。
- [ ] 人和背景拉开距离、明暗或颜色有反差，抠像更干净；穿纯色衣服，避开细条纹。
- [ ] 主光从侧前方打。颜色主要在拍摄时定，后期只做轻量纠偏。
- [ ] 三脚架全程不动。原位抠像依赖这一点。

## 内容
- [ ] 口播稿写短句，每句 10–15 字，一句一个意思（一句对应一个画面）。
- [ ] 在稿子里标出想配图卡的句子，以及大概放什么（数字、列表、截图、对比）。
- [ ] 截图、录屏素材一起准备好。录屏选最精彩的几秒就够。

## 交给 AI 的东西
1. 原始视频（不要先剪）
2. 口播稿
3. 一句话：这期最想突出什么
