# 风格卡：白底蓝光（示例）

> 风格卡 = 「一个世界，一套物理」。机制（排版状态、交接、音效绑定、节奏）全片不变，换风格只换这一层皮。
> 这是作者自己挑定的风格（`styles.js` 里的 `tech-1`），用来示范一张风格卡该写什么。
> 用户在第 3 步选完风格后，照这个格式给他写一张，下次直接用。

## 一句话气质
讲 AI 和工具，有一点科技感，但明亮、干净、不压抑。不走暗夜霓虹路线。

## 颜色
| 用途 | 值 | 说明 |
|---|---|---|
| 底色 | `#F3F5F9` 浅灰白 | 图卡段落的背景 |
| 底纹 | 48px 细网格，透明度约 6% | 像设计稿的画布 |
| 柔光 | 左上一团蓝 `rgba(77,140,255,.28)`，右下一团青 `rgba(80,200,230,.20)`，缓慢漂移 | 让白底不死板 |
| 主强调色 | `#2F6BFF` 蓝，渐变到 `#16B5E8` 青 | 编号、胶囊、进度条、高亮框 |
| 文字 | `#14181F` 近黑，次要信息 `#5A6475` | |
| 卡片 | 纯白，圆角 18，柔和蓝灰投影 | 截图一律放进白色 Mac 窗口（三个红黄绿点） |

只用**一个**强调色。需要表达「错误 / 风险」时才临时加红色。

## 字体
- 中文：Noto Sans SC，标题 900，正文 500–700。
- 英文小标签、编号：JetBrains Mono 700，全大写、加宽字距（如 `PART 01`、`DEMO · 3 POINTS`）。

## 人
- **小圆头像**：直径约 200px，白色描边，圆框里头只占一半、露出肩膀。
  位置可选 `top-left` / `top-right`（`config.js` 的 `avatar.corner`）。叠加元素（章节卡、便签、小标签）自动放在头像的对侧。
- 讲到产品素材（录屏、游戏实玩）时素材铺满，也保留小圆头像，不要整段把人隐去。
- 原位抠像：人在原画面里的位置和大小不变，只把背景换成白底网格。
- 可选：把人抠出来放进明亮干净的房间背景（需要另做合成，模板不包含）。

## 运动
- 进场：弹簧（damping 15，stiffness 170），从下方 30–50px 上移 + 轻微放大，不夸张回弹。
- 退场：0.3 秒淡出。状态交接一律 0.3 秒淡入淡出，人不移动。
- 列表、三张卡逐个出现，间隔约 0.33 秒。

## 字幕
底部居中一行，白色 900 粗字 + 约 7px 深色描边，关键词 `#4DB5FF`。

## 对应的 config.js
```js
style: 'tech-1',
avatar: {corner: 'top-right', ...},
```

## 做自己的风格卡
不要凭空写：先按 `style-picker.md` 出样板让用户挑，挑定后再把选择结果和他说过的偏好写成风格卡。
