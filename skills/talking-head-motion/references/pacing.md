# 节奏

- **气口松紧和要不要加速，由用户决定**（`cutting.md`）。`npm run raw` 会测出语速并给建议：
  - 日常聊天约 4–5 字/秒；节奏紧凑的知识类口播博主约 6.3–6.6 字/秒。
  - 用户选了才加速，常用 1.1 或 1.2 倍；加速保留音调。
  - 「快」的感觉主要来自去掉气口，不一定靠加速。
- **句间不留空档**：说完一句马上接下一句。用户能精确到 0.5 秒指出多余停顿，所以剪的时候要看波形。
- **停够让人看清，然后就走**：画面内容全部出现后，最多再停约 1 秒就切。看不清就放大关键信息、加停留，不要降速。
- **空档用素材填**：需要等待的时间，用录屏、实玩画面填，不要放一张静止的图干等。
- **具体产品 / 作品**：只放素材里最精彩的几秒（3–4 秒），不要太长。
- 一个字的强调（如「发」），后面停 1 秒就够。
- 检查：`npm run check`。内容没出全就切走、话说完还停着、句间停顿太长、连续干讲超过 10 秒，都会指出来。
