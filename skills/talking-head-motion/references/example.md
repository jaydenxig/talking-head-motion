# 范例：一条教程口播的开头一分钟

照着抄用的。素材是作者的一期视频《AI 自动化投简历》开头（竖屏，小头像版式，1.1 倍速）。
从「挑句子」到「写分镜」每一步填了什么、为什么这么填，都在这里。拿不准的时候，先找这里最像的那一镜。

## 第一步：挑句子（`src/takes.js`）

`npm run raw` 标出来的，逐条核对后都确实是重讲：

```js
{id: 'R036', keep: false, text: '如果是我的话,我会提前准备好', why: '像是说到一半换了说法：停了 2.32 秒后 R037「我的话是直接把提前准」把这件事重说了一遍'},
{id: 'R040', keep: false, text: '那这岗位方', why: '话没说完就断了，后面 R041「那这岗位方面我会优先」重新说了'},
{id: 'R047', keep: false, text: '比如说薪资要求写一万', why: '像是说错重来：和 R048 开头一样，留后一遍'},
```

程序没标、通读时自己找出来的：

```js
// （停了 1.08 秒）
{id: 'R102', keep: false, text: '接下来就意味着'},   // 半句，没有结论
{id: 'R103', keep: false, text: '你的室友'},         // 半句；后面换了个开头重说
{id: 'R105', keep: true,  text: '等你把这一切都设置好安排完'},
```
认出它的线索：句子停在「就意味着」这种半句上，前后都有停顿，后面那句另起了一个头。

顺手对稿（只改 `text`）：`自动画头简历` → `[自动化投简历]`，`Claud` → `Claude`，`针对新的建议` → `[针对性的简历]`。
一个词被断在两句之间（`…拿到一个薪` / `资翻倍的…`），把字挪到同一句：`…拿到一个` / `薪资翻倍的…`。

## 第二步：对素材（`npm run needs`）

写分镜之前先对一遍：哪些话在讲具体操作或具体东西、手上有没有能配的画面。这一期的结果：

| 句子 | 最好有什么 | 现在有没有 | 怎么办 |
|---|---|---|---|
| 「四天…拿到面试」 | 能证明的截图 | 有：面试邀请邮件 | 用现有的（糊真名） |
| 「无数个来要简历的消息」 | 消息列表截图 | 有：招聘软件的消息页 | 用现有的（糊公司名、薪资、真名） |
| 「给它发一段提示词…把简历发给它」 | 对话的截图或录屏 | 没有 | 问了用户，补不了 → 用对话卡演 |
| 「挖掘亮点…生成针对性的简历」 | 生成结果的截图 | 没有 | 用文档卡演 |
| 「能够操作网页」 | 界面截图 | 有：Muse 的浏览器卡片 | 用现有的 |

**顺序是：有真素材用真的 → 没有但讲的是动作，用动作卡演（对话 / 流程 / 文档，会标「示意」）→ 确实只是几个并列要点，才用文字清单。**

## 每一镜为什么这么排

| 你说 | 放了什么 | 为什么 |
|---|---|---|
| 「我真的没有期待用它找到工作，但事实就是」 | 整张脸 + 便签「4 天，约到外企 AI 岗面试」 | 开头三秒先立结果。便签自动放在头顶上方的空处，不压脸 |
| 「它只花了四天就…外企 AI 岗位的面试」 | 面试邀请邮件，框「线上初试」 | 口说无凭，放真截图；真名糊掉 |
| 「还有无数个来找我要简历的消息」 | 招聘软件的消息列表（只显示前四行） | 「无数个」要让人看见「多」；公司名、薪资、真名全糊 |
| 「虽然没有成功入职…真的很有用」 | 不配，整张脸 | 说感受的话留给人脸 |
| 「我是如何通过 AI 来自动化投简历的」 | 流程卡：我的简历 → AI 助手 → 招聘平台 | 点题的同时让人一眼看懂整件事怎么运转，比只打一个标题有信息量 |
| 「现在正好是秋招…希望对你有用」 | 不配 | 过渡句，5 秒，没超过 10 秒的上限 |
| 「第一步，优化我们的简历」 | 章节卡 STEP 01 | 进入新的一部分 |
| 「打开一个你经常用的 AI 软件，不管是豆包还是 Claude」 | 两张小卡：豆包 / Claude | 给选项；用通用文字，不放真实 logo |
| 「给它发一段提示词…把你最新的简历发给它」 | 对话卡：两句话一个字一个字打出来，简历文件飞进对话框 | 这是在讲一个动作，没有真截图就演出来；不退成一张五条的文字清单 |
| 「结合…目标岗位，挖掘出简历里没有体现的亮点，生成针对性的简历」 | 文档卡：光扫过简历，划出两条重点，最后盖上「针对性简历」 | 「挖掘」「生成」都是动作，画面上真的发生一次 |
| 「完成了我们的准备阶段」 | 不配 | 收尾句 |
| 「第二步，下载一个个人 AI 助手」 | 章节卡 STEP 02 | 没有演示下载过程：演示境外软件的下载登录有被平台限流的风险 |
| 「只要能够操作网页就可以了」 | Muse 的浏览器卡片截图，框「打开浏览器」 | 「操作网页」是抽象的，看到它真的开了一个浏览器才懂 |

## 没放的，和为什么

- 「豆包」「Claude」的官方图标：不用真实品牌的 logo。
- 「薪资翻倍」的证据：作者不想公开工资。没有证据的话不配图，也不编一张。
- 「文科专业、没有 AI 行业背景」：说的是自己，放字反而像在念简历。
- 每句话都配一张卡：观众每两秒要认一张新图会很累。全片约三分之一的时间是整张脸。

## 常见的坏例子 → 好例子

| 坏 | 为什么坏 | 好 |
|---|---|---|
| 他说「效率贼高」，画面弹出一个胶囊「效率贼高」 | 和说的一字不差，字幕已经有了 | 不配；或者放一个能说明效率的数字 |
| 用几行字拼一个聊天窗口，冒充真实对话 | 观众会当成真截图 | 用真截图；确实要自己画的，加 `mock: true` 标「示意」 |
| 整张手机长截图塞进画面 | 字小得看不清 | `crop` 只留要讲的那几行，或 `scroll` 滚动 |
| 讲「把简历发给它，它生成一份新的」，画面是一张五条的文字清单 | 这是动作，不是要点；列成字就是会动的 PPT | 有截图录屏用真的；没有就用对话卡、文档卡把动作演出来 |
| 便签、章节卡贴在嘴上、下巴上 | 挡脸 | 位置是按脸自动选的；检查器报「会压到脸」就把字改短或不放 |
| 一张清单一出场五条全亮 | 观众读完了，你才讲到第二条 | 每条写 `at`，说到哪条亮哪条 |
| 讲感受、讲观点时也切到图卡 | 观众想看的是你的脸 | `state: 'full'` |
| 糊掉整张截图 | 截图就没用了 | `mask` 只糊名字、公司名、金额那几个字 |
