# 逐句分镜

## 原则
1. **先声后画**：口播定稿、剪紧之后，才按句子时间轴排画面。
2. **一句话，一个画面意图**。约每 1.5–2 秒要有一次画面变化（新卡片、新一行、高亮、切状态都算）。
3. **排版状态只有三种**，切换只发生在句子边界：
   | state | 画面 | 适合 |
   |---|---|---|
   | `full` | 全屏口播，可叠章节卡 / 便签 / 小标签 | 观点、过渡、情绪句 |
   | `pip` | 白底网格 + 图卡 + 小圆头像 | 截图、数据、列表、产品素材 |
   | `cutout` | 原位抠像 + 图卡 | 总结、对比、「人站在信息旁边」 |
4. 角落小标签说明「这是什么」（如「某某做的游戏 · 实机画面」）。
5. 开头不直接给结论：先放最抓人的素材几秒，再说观点。结尾回到开头，带着变化。

## 先给人看的分镜表
| # | 时间 | 你说 | 画面 |
|---|---|---|---|
| 1 | 0.0–3.5 | （原话） | 素材铺满 + 小头像 + 左上标签 |
| 2 | 3.5–6.9 | … | 图卡：截图框出重点 + 一句结论胶囊 |

表头写一句：「想改哪里，直接用大白话说『第几段换成什么』」。

## 写进模板
`template/src/shots.js` 每一镜：
```js
{from: 9.0, to: 13.4, state: 'pip',
  card: {type: 'window', title: '窗口标题', img: 'shot-03.png', pill: '一句结论'}}
```
卡片类型：`cards3`（三点）、`window`（截图 / 消息，可 `highlight` 圈重点、`zoom` 放大）、`list`、`stat`（数字滚动）、`pill`、`quote`。
叠加层：`overlay: {type: 'chapter' | 'note' | 'tag', ...}`。
需要新卡片类型时照着 `Talk.jsx` 里现有组件加，并在 `sfx.js` 的 `cardBeats` / `buildSfx` 里登记它的出场帧和音效。
