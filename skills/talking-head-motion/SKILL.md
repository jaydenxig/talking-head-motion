# 口播动效（talking-head-motion）

把一条横屏真人口播做成「人始终在场、每句话有画面、音效跟着动作走」的短视频。
底座是 Remotion（用 React 写动画、渲染成 MP4），模板在 `template/`。

**核心分工**：AI 产出零件（分镜初稿、图卡动画、字幕、音效点位），人做导演（选题、口播、风格、每句话怎么排、挑版本）。
**省钱原则**：先用静帧和几秒的小动图让人确认方向，再做整片。用户没勾选的部分一律不做。

## 第 0 步：先问用户这次要做哪些部分

开始任何生成之前，先让用户勾选（在 Claude Code 里用多选提问工具；没有这个工具就列成编号清单让他回复编号）：

| 模块 | 说明 | config.js 开关 |
|---|---|---|
| 图卡动效 | 截图窗口、三点小卡、清单、数字等 | `modules.cards` |
| 章节卡 / 便签 / 小标签 | 叠在全屏口播上 | `modules.overlays` |
| 小头像 | 图卡段落里的人像小窗 | `modules.avatar` |
| 字幕 | 烧进画面，同时给 .srt | `modules.subtitles` |
| 音效 | 真实录音，跟着动作走 | `modules.sfx` |
| 配乐 | 推荐几首可商用纯音乐给他试听、挑选 | `modules.music` |
| 封面 | 4:3 和 3:4 两张 | — |
| 发布文案 | 各平台标题、简介、话题、章节时间点 | — |

没勾的模块：不出样板、不写分镜、不渲染、不写文档。比如没勾字幕，就不做语音识别对字幕；没勾配乐，就不推荐曲子。
把选择结果写进 `template/src/config.js` 的 `modules`。

## 第 1 步：听内容，判断类型

1. 有口播稿就读稿；没有就先做语音识别（中文可用 sherpa-onnx + SenseVoice 等本地模型）。
2. 看几帧画面（ffmpeg 每秒抽一帧拼成一张图）。
3. 判断内容属于哪一类（`references/style-picker.md`）：科技 / 生活 / 家庭 / 知识 / 商业 / 美食旅行。拿不准就选两类各出一部分。
4. 用一句话告诉用户你的判断：「这期讲的是 ×××，我按『生活类』出风格样板」。

## 第 2 步：出风格样板（只针对勾选的模块）

1. 从这期口播里挑几句话，填进 `template/src/samples.js`，让样板看起来就是这期视频。
2. 运行 `node tools/make-samples.mjs --category <类型>`（或 `--styles a,b,c` 指定）。每套风格出：
   - 4 张静帧：全屏口播 + 章节卡 / 三点小卡 / 截图窗口 / 清单（都带字幕和小头像）
   - 1 段 4 秒小动图：带这套风格的动效和音效包，能听到声音
   - `样板说明.md`：每套的配色、字体、卡片、头像形状、动效、音效包、字幕各是什么
3. 每一类至少 3 套，可以再加 1 套别的类当对照。勾了配乐就按 `references/music.md` 给 3–5 首候选曲的试听链接。
4. 把总览图、小动图和说明发给用户。

## 第 3 步：让用户挑选或混搭

逐项提问（多选提问工具，每项一个问题，选项是 A / B / C…）：配色、字体、卡片样式、头像形状、动效、音效包、字幕样式、配乐。
- 只喜欢某一整套：直接选那一套。
- 混搭：比如「配色要 A，字体要 B，头像要 C」。写进 `config.js`：
  `style: {base: 'travel-1', font: 'travel-2', avatar: 'hex'}`（每项可以写风格编号或零件名，零件名见 `src/styles.js`）。
- 用 `--mix` 出一张混搭后的确认图，用户点头后再往下走。
- 选定的结果记成这个用户的风格卡（`references/style-card.md` 的格式），下次直接用，不用再挑。

## 第 4 步以后：做整片（先声后画）

1. **声音先定稿**：降噪、轻压缩；1.1 倍速（保留音调），目标约 6.3–6.6 字/秒；剪掉气口和句间多余停顿，剪切点尽量藏在图卡出现时。
2. **逐句分镜**（`references/storyboard.md`）：一句话一个画面意图；状态只有 `full` / `pip` / `cutout`，只在句子边界切换，交接 0.3 秒。输出一张表给用户用大白话改。
3. **写进模板**：分镜 `src/shots.js`，字幕 `src/subs.js`。
4. **节奏检查**（`references/pacing.md`）：`node tools/check-pacing.mjs`。
5. **音效**（`references/sound.md`）：模板按动作自动挂选定音效包里的声音，和动画同帧。只用真实录音。
6. **打码**（`references/masking.md`）：只打有法律风险的信息，小块马赛克。
7. **渲染**：先出几张静帧检查，再整片渲染。字幕（`references/subtitles.md`）烧进画面，并导出 `.srt`（`node tools/make-srt.mjs`）。
8. **配乐**：用户选了曲子就放到 `public/`，打开 `modules.music`，模板会只在图卡段落把音乐抬起来、口播时压低；也可以让用户自己在剪映里加。
9. **发布包**（用户最后剪完后）：封面见 `references/cover.md`，各平台文案见 `references/publishing.md`。

## 每期结束后

把用户这期提的每条修改记下来（说了什么、改成什么、为什么）。同一类修改出现两次以上，就写进他的风格卡或这份 skill 的规则里。

## 不要做的事

- 不要跳过第 0 步直接出整片。
- 不要用合成或 AI 生成的音效和配乐，这是「AI 味」的主要来源。
- 不要让画面静止等待：空档用素材填，或者剪掉。素材是动态的就用动态。
- 讲到具体产品 / 作品时，只放素材里最精彩的几秒。
- 不要大面积打码，也不要漏掉别人公司名这种有风险的信息。
