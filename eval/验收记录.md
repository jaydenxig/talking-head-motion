# 验收记录：换成 DeepSeek，这套做法能不能做对

日期：2026-11-17　模型：`deepseek-flash`（通过 `eval/run.mjs` 接入，只给读文件、改文件、跑命令三样工具）

## 结论

**能做对，而且做得不差。** 四道题全部通过。只要流程和检查器把关，弱一档的模型能把「挑句子」和「写分镜」做到可以交给人审的程度。
它做不到的主要是**看图**：截图裁哪块、露出来的内容对不对。这一块靠新加的检查补上之后，重考就没有再犯。

| 考题 | 结果 | 说明 |
|---|---|---|
| 挑句子（程序先标了 7 句） | **10 / 10**，0 误删 | 核对了程序标的 7 句，又自己通读找出程序认不出的 3 句（说到一半换说法、分段重录时多出来的过渡句） |
| 挑句子（裸考，没有任何提示） | **9 / 10**，0 误删 | 漏的那句（分段重录前的「那还有一个问题」）它在汇报里主动提出来，说衔接可能别扭，请用户定 |
| 写分镜（一条求职教程的开头一分钟） | 通过，0 错误 | **参考价值有限**：范例文档用的就是这条素材，它基本照着范例排了 |
| 写分镜（一条产品体验口播的前一分半，横屏，没有范例） | 初考通过，3 处问题；**重考 0 错误 0 提醒** | 这是真正的考试。见下文 |

几个过程上的好习惯，比分数更说明问题：

- 每一步都先跑 `npm run next`，照它说的做；检查报错就照报错改，改到通过。
- **没有替用户拿主意**：考题没授权的确认，它停下来写「等你点头」；考题明确说「直接确认」的，它才确认。
- 没有改过任何不该改的程序文件。越界只发生在命令上（想自己装依赖、想用 `node -e` 打印清单、想把两条命令连起来跑），都被拦下，没有造成影响。
- 素材全部用上；讲动作的句子用对话卡、流程卡演出来，没有退成文字清单；每张卡都写了「观众能明白什么」。

## 暴露出来的问题，和改法

第二道写分镜题（没有范例）初考时，检查器零错误，但渲染出来人一看就有三处毛病：

| 毛病 | 原因 | 改法 | 重考 |
|---|---|---|---|
| 一张截图裁出来右边空了一大半 | 模型看不见图，按坐标估着裁 | 「量一量」时算每块裁切里内容占了多少，少于 55% 就提醒，并说明哪边空 | 没再出现 |
| 讲「每天提醒好几回」，截图里露出来的却是另一条讲别的事的通知 | 一张截图上有好几条消息，模型没核对露出来的是哪条 | 分镜表末尾列出每张截图实际露出来的字；看图工具加 `--crop`，只读这一块 | 裁到只剩要讲的那条 |
| 同一条通知隔了几镜又放了一次 | 没有任何规则管这个 | 检查器发现隔开的两镜放了同一张图的同一块，就提醒 | 只放了一次 |
| 只框了一个字「早」 | 框的字太短 | 框的字少于 2 个，提醒写完整的词 | 改成框整句 |
| 短引用在画面中间只有一行小字 | 模板的问题 | 12 个字以内的引用放大当主角 | — |
| 小卡、流程卡的字在半中间折行 | 模板的问题：卡片宽度写死了 | 卡片宽度按最长那条字算 | — |
| 写分镜一次用掉 160–240 万 token | 模型把检查器的程序代码分好几次读了一遍 | 入口说明里写明「不用读程序代码」 | 降到 133 万 |

## 还管不到的

- **好不好看还要人看。** 检查器只管「对不对」：没有错、没有挡脸、没有裁空、没有重复。镜头排得有没有意思、节奏好不好，要看渲染出来的片子。
- **录屏从第几秒开始放**，模型看不了视频，这次是写在考题里告诉它的。真用的时候要问用户。
- **示意动画里的话是模型编的。** 比如对话卡里「你连着三天在看 AI 模型，这块我可以每天帮你盯」，会标「示意」，但说得合不合事实要用户过目。
- **图卡段落仍会被自动检测判成「定格」**（卡片出全后只有小头像在动）。3% 的慢推不够明显，观感要人判断。
- 没测：Grok（没有账号）、`deepseek-v4-pro`、竖屏素材从剪口播到出片一口气做完。

## 用量

五次考试合计：读约 589 万 token，写约 9.4 万 token。挑句子一次约 30 万，写分镜一次 130–240 万。
读的部分大多是每一轮重复发送的历史对话，能命中缓存。实际扣费以 DeepSeek 后台为准。

## 怎么复现 / 考别的模型

见 `eval/README.md`。在 `eval/.env` 里换三行（接口地址、密钥、模型名），再跑：

```bash
node eval/run.mjs --case eval/cases/<考题名>
```

考题和考试过程（`eval/cases/`、`eval/work/`）里有作者自己的素材，不提交到仓库。
