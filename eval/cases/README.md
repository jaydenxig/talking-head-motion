# 考题

每道考题一个文件夹，放在这里。**这个文件夹里的内容不会提交到仓库**（考题里是你自己的素材）。

一道考题由三样东西组成：

- `task.md`：交给模型的话。用户不在场，所以要把它可能会问的事提前答好。
- `truth.json`：标准答案和评分方式。
  - 挑句子：`{"type": "takes", "drop": ["R036", "R040"], "needHit": 2, "allowWrong": 1}`
  - 写分镜：`{"type": "shots", "assets": ["mail.jpg", "browser.png"]}`
- `overlay/`：考试开始时的状态，目录结构和仓库一样，会盖到仓库副本上。
  大文件（原始视频）不用复制，建一个同名加 `.link` 的文本文件，里面写它的绝对路径。

出一道新题最省事的办法：自己手工做一期，把做到一半时的 `src/` 和素材拷进 `overlay/`，把你最后定稿的结果当标准答案。

发给模型的内容会经过对方的服务器。考题里的截图如果有真名、公司名、金额，先永久糊掉再放进来。
